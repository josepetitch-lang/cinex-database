# Cinex Database System 

Este proyecto es un sistema de gestión para una cadena de cines, desarrollado con **Python** y **SQLite**. 
Aplica conceptos de Programación Orientada a Objetos (POO) y arquitectura de servicios para manejar la lógica de negocio.

##  Arquitectura del Proyecto
El sistema está organizado de forma modular para facilitar su mantenimiento:

- **Data/**: Gestión de la conexión y creación de la base de datos (`db.py`).
- **Models/**: Definición de clases (Usuarios, Salas, Taquillas).
- **Services/**: Lógica de negocio (Gestión de ventas y asignación de taquillas).
- **Main.py**: Punto de entrada para la ejecución del sistema.

## Funcionalidades.
- Gestión de salas y disponibilidad de asientos.
- Procesamiento de ventas a través de taquillas automatizadas.
- Persistencia de datos en SQLite.
